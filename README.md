# 红果净化

红果短剧专用 iOS 越狱插件，让界面与播放习惯按你的选择调整。

[官网](https://hongguo.goforit.si) · [下载最新版本](https://github.com/5hux1n/hongguofn/releases/latest) · [插件源](https://apt.mjh.im)

本仓库用于发布插件安装包与使用说明。

## 安装

适用于 **iOS 15 及以上的越狱设备**，当前适配 **红果短剧 7.3.9**。

在 Sileo 或 Irisin 添加 `https://apt.mjh.im`，搜索“红果净化”，选择对应越狱方案安装。也可以从 [Releases](https://github.com/5hux1n/hongguofn/releases) 下载 DEB。

| 越狱方案 | 安装包 |
| --- | --- |
| Rootless | [arm64 DEB](https://github.com/5hux1n/hongguofn/releases/download/v1.0.1/hongguofn_1.0.1_iphoneos-arm64.deb) |
| RootHide | [arm64e DEB](https://github.com/5hux1n/hongguofn/releases/download/v1.0.1/hongguofn.roothide_1.0.1_iphoneos-arm64e.deb) |

安装后彻底关闭红果短剧，再重新打开。插件设置入口位于 **我的 → 设置 → 红果净化**，在“清理缓存”上方。

## 功能

- **观看页面净化**：按需隐藏金币挂件、发送弹幕按钮、作者声明、系列剧入口、爆剧标志、榜单、热评、剧标签、AI 标识和短剧备案号。
- **导航与启动页**：顶部频道、底部导航可多选隐藏，默认启动页与首页频道分别设置。
- **播放控制**：短剧广告控制、进度条时长显示、关闭进入自动播放，支持 App 内原生本地下载。
- **倍速与清晰度**：长按默认倍速支持滑块和步进器，范围 0.5～3.0 倍、每步 0.05；可自动按配置倍速播放，并锁定视频清晰度。
- **自动清屏**：播放时进入原生清屏模式，可选择暂停时退出清屏。
- **个人中心净化**：隐藏整组快捷入口，按需显示会员状态卡片。
- **提醒净化**：隐藏红点提醒、两侧栏游戏中心，减少开启通知的提示。
- **独立开关**：沿用 App 原生设置样式，总开关关闭后保留已有配置。

修改导航或启动页后，彻底关闭 App 再重新打开。会员状态是本地显示，实际账号权益以账号为准。本地下载保存在 App 内。
