# 红果净化

红果短剧专用 iOS 越狱插件，让界面与播放习惯按你的选择调整。

[官网](https://hongguo.goforit.si) · [下载最新版本](https://github.com/5hux1n/hongguofn/releases/latest) · [插件源](https://apt.mjh.im) · [问题反馈](https://pingme.pm/hongguo)

本仓库用于发布插件安装包与使用说明。

## 安装

适用于 **iOS 15 及以上的越狱设备**，当前适配 **红果短剧 7.4.1**。

在 Sileo 或 Irisin 添加 `https://apt.mjh.im/`，搜索“红果净化”，选择对应越狱方案安装。也可以从 [Releases](https://github.com/5hux1n/hongguofn/releases) 下载 DEB。

| 越狱方案 | 安装包 |
| --- | --- |
| Rootless | [arm64 DEB](https://github.com/5hux1n/hongguofn/releases/download/v2.0.0/hongguofn_2.0.0_arm64.deb) |
| RootHide | [arm64e DEB](https://github.com/5hux1n/hongguofn/releases/download/v2.0.0/hongguofn_2.0.0_arm64e.deb) |

安装后彻底关闭红果短剧，再重新打开。在 **我的 → 设置 → 红果净化** 打开插件总开关，再按需开启分项功能。隐藏“我的”后，可双指长按底部导航打开插件设置。

## 功能

- **观看页面净化**：按需隐藏金币挂件、弹幕入口、作者声明、系列剧入口、爆剧标志、榜单、热评、剧标签、AI 标识和备案号；头像、收藏、分享、评论、爱心按钮分别控制。
- **导航与启动页**：顶部频道、底部导航可多选隐藏并即时生效，默认启动页与首页频道分别设置。
- **播放控制**：短剧广告控制、进度条时长显示、关闭进入自动播放、双击视频打开评论区。
- **倍速与清晰度**：左右侧长按倍速独立设置，可锁定默认播放倍速和视频清晰度。
- **清屏**：播放时自动清屏、完整清屏及隐藏状态栏，暂停后按配置恢复。
- **相册保存**：本地视频保存到系统相册、保存进度提示、下载完成后自动保存。
- **小说阅读**：隐藏奖励挂件、双击自动阅读、解除自动阅读广告限时。
- **自动福利**：自动签到、领取宝箱、红包与存钱罐奖励、完成预约任务。
- **其他净化**：个人中心快捷入口、红点提醒、侧边栏游戏中心、截图识同款挂件与福利引导气泡可按需隐藏。
- **独立开关**：总开关关闭后保留已有配置；未保存的开关默认关闭。

## 使用说明

在插件设置中选择需要的功能。自动福利需开启对应任务开关；保存到相册需允许照片权限。原生本地下载保存在 App 内，保存到相册后可在系统“照片”中查看。

会员状态卡片为本地显示，不改变账号权益。
